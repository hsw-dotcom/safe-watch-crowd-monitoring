# Safe Watch 2023 대화 및 보고서 대조 기록

> 2026-10-31 작성된 자료 감사·검증 문서입니다. 실제 2023년 원본 실행 로그나 당시 작성한 코드 파일은 아닙니다. 프로젝트 내 검색 가능한 과거 대화와 2023년 발표자료·34쪽 개인 최종보고서를 바탕으로 합니다. **모든 과거 대화 메시지를 빠짐없이 다운로드·감사했다고 주장하지 않습니다.**

## 최종 동작 판정: 이번 사용자 정정 반영

- **위험 단계**: 면적당 인원 수를 계산하려는 **초기 설계는 구현하지 못함**. 최종 구현은 사람 수 **0~2 안전, 3~4 경고, 5 이상 위험**. 최종 발표와 2026-10-31 사용자 설명이 일치함. 보고서 `main.py`는 그 이전의 면적기준 산식으로 판단됨.
- **면적 측정**: 동적 산출 없음. 고정 `total_area=300`을 사용한 보고서·보관 코드의 밀집도 표기값이 존재하지만, **실측 면적이나 장애물 차감 값을 계산했다고 설명하면 안 됨**. `get_obstacle_area`는 비완성·비연결 함수.
- **모델**: 사람이 인식되는 TFLite 모델은 Raspberry Pi에서 추론만 수행. 모델 추출·변환 이후 현장 장치에서 재학습하지 않음. 장애물 모델 17종은 학습 후 정확도·용량·처리 자원 문제로 탑재에서 제외. IoU 중복박스 통합은 계획이지 최종 구현 아님.
- **사진**: `before.jpg`·`after.jpg`를 같은 파일에 덮어쓰기. 웹 `/tensorflow/after.jpg?timestamp` 2초 갱신.
- **기록 주기**: 사용자 10초 확인, PDF `configs.ini`도 10초. 과거 보관 설정 15초는 다른 버전. `main.py`의 처리 후 `time.sleep(delay_time)`은 시작 주기 정확히 10초를 보장하지 않음.
- **변화 그래프**: 사용자는 최종 사용을 **백분율 변화율(%)**이라고 확인. 현재 보관 SQL이 그 공식이고, 2023 보고서는 백분율을 밀집도 절대 차이로 바꿨다고 기술하는 반대 근거가 있음. 어느 SQL 바이트가 당시 최종 DB에 사용됐는지는 확인 불가.
- **문자 알림**: 최종 발송은 `alarm.py` Twilio. `maininfo.html`의 `127.0.0.1:5000/send_sms` 요청은 과거 실험 흔적. Flask `app.py` 원본과 성공 로그는 확인되지 않음.

## 개인 최종보고서에서 추가 확인되는 개발 순서

1. Raspberry Pi 4 / Camera Module v3, Raspbian 설치와 VNC 원격 접근. 소프트웨어 작업 병렬 진행.
2. PC에서 Nginx, PHP, MariaDB 웹서버와 HTML·AJAX 테스트 후 Raspberry Pi 서버로 이전.
3. 스트리밍 실패·재시도 끝에 Picamera2 MJPEG `:8000` 구축. `motion` 포트 8081은 과거 대화에서 제안됐지만 최종 코드에 없는 대안.
4. 웹의 시계 1초 갱신, 위험 단계 배경 녹색/노란색/빨간색, 정보페이지 갱신 10초, 그래프 PHP 폴링 1초. **이 UI 갱신 주기들과 사람 인식 10초는 서로 다른 작업**.
5. 두 웹 그래프는 최근 DB 20건을 표시하고, CCTV 위치는 Google Maps 임베드를 사용.
6. 경고 상태에 대한 웹 모달 및 USB 스피커 경고음을 시도하며, 웹에 접속한 PC에서 소리가 나던 문제를 개선했다고 보고서에 기술. 최종 SMS는 Python의 `alarm.py` 경로.

## 실제 시험과 증거 경계

2023 보고서는 명지대학교·기흥역 근처 야외 시험에서 높은 위험 수준으로 진입하지 못해 SMS 및 스피커의 실제 위험 상황 자동 연동 검증이 이뤄지지 않았다고 명시. 5m 근처 일부 인원 감지, 10m 이상 인식률 저하와 마네킹 오인식 기록. 휴대전화의 Twilio 문자 실제 수신은 다른 증거로 인정하되 군중 위험에서 자동 발생했다고 주장하지 않음.

모델/라벨/WAV는 별도 `backup.zip`에서 존재가 확인되었으나 공개 Git에는 포함하지 않음. 얼굴, 시험 영상, SMS의 실제 연락처나 Twilio 계정값을 공개하지 않음.
