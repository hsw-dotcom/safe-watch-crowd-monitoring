# 2023 Safe Watch 코드 복원 근거와 한계

## 확인된 자료
- **4조 최종 발표**: 1~2명 안전, 3~4명 경고, 5명 이상 위험. CCTV 인식, 경보/문자, 웹 서버, MariaDB, 그래프, 지도, TFLite.
- **4조 6월1주차 발표**: 웹 이미지 최신화, DB 주기 갱신, 밀집도·변화율 그래프, Google 지도, 학습 및 IoU 향후 계획.
- **보관된 2023년 원본 코드**: `main.py`, `count_objects.py`, `stream.py`, `alarm.py`, SQL, HTML/PHP/JS. 코드의 면적/밀집도 판정은 최종 발표와 일부 불일치.
- **2023년 프로젝트 질의응답**: `/tensorflow/after.jpg`, 2초 갱신, `?` + 타임스탬프, PHP·AJAX 연계 및 SMS 경로.
- **사용자 직접 확인**: 최종 발표를 우선. 모델 변환·추출 후 수정 없음. 구역 면적은 고정값. 이미지는 같은 경로를 덮어씀. 0 나눗셈 방어를 별도로 구현하지 않았던 것으로 기억.

## 현재 복원본의 의도적인 차이
1. **최종 발표 기준으로 위험 단계 교정**: 과거 `main.py`에서는 `people_count / total_area`에 2,4를 적용하였으나 발표 기준 2명/5명으로 판단하도록 변경. 밀집도 값 자체는 `사람수/고정면적300` 그대로 유지.
2. **단순 이미지 덮어쓰기**: 원래처럼 `cv2.imwrite(before.jpg)`와 `cv2.imwrite(after.jpg)`로 갱신하고 후대의 임시 파일/원자적 교체를 제거.
3. **모델은 고정 파일**: 학습/변환은 복원본에 포함하지 않음. 매 검출 시 기존 TFLite 파일 로드. 이미지의 상자 표시와 인원 계산만 수행.
4. **SQL은 역사적 구조 우선**: `receive_data.people_count` 추가 열 제거, `density` VIEW는 직전 `id + 1` JOIN 사용, 이전 값=0 분기 추가하지 않음. 초기 `cameras` 등록은 FK 오류 방지용 새로운 설치 보정으로 명시.
5. **경고는 원본과 같은 반복 호출**: 10초 DB 조회 시 위험이면 WAV/SMS 호출, 300초 쿨다운 제거. SMS는 의도치 않은 발송을 피하려고 opt-in (실제 2023 코드에 없던 운영 안전장치).
6. **검증/중복정리 편의**: Python 유틸 함수 분리, 단일 PHP API, HTML 그래프 통합, 테스트, 합성 데모, 환경변수 설정은 당시 원본 그대로가 아닌 현재 정리 방식.
