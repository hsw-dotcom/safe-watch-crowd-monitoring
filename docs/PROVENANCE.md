### 코드 복원과 사용자 검증의 경계
- 실제 2023 코드 파일은 GitHub 이력 및 보관 브랜치에 보존합니다. 이 `main`의 `src/`는 **재작성·개선본**으로, 당시 코드의 1:1 원문이 아닙니다.
- 이전 대화의 ZIP(`개발코드.zip`, `backup.zip`, `제출자료.zip` 등)은 파일 존재와 크기를 확인했으나 원본 압축 내부를 완전히 대조하지 못했습니다.
- `app.py`는 대화 속 경로만으로 작성된 *선택적* Flask 재구성으로서 실제 원본이 없고, 주 동작 `alarm.py`와 책임이 중복되어 정리본에서 제외했습니다.
- DB 밀집도 VIEW는 카메라별 직전 샘플을 조회하고 이전 값 0을 처리하도록 수정했습니다. `people_count` 칼럼은 신규 설계입니다.
- `max_iterations`, 딥러닝 인터프리터 재사용, alert cooldown, 외부 시크릿 분리, 웹 demo 모드는 복원 이후의 개선 사항입니다.
- 원본에서 사용한 인원/면적 비율과 위험 경계를 유지했지만 모델 결과와 임계값의 물리적 타당성을 입증하지 않습니다.
