# 2023년 실물·문자 증거와 공개 범위

> 이 문서는 2026년에 작성한 검증 메모입니다. 2023년 당시 소스 또는 시스템 실행 로그 자체가 아닙니다. 사진·영상과 원본 바이너리는 개인정보·초상권·재배포 권리를 고려해 공개 저장소에서 제외했습니다.

## 별도로 확보된 2023년 파일
2026년 추가 제출된 `backup.zip` 정리에서 다음의 파일 존재를 확인했습니다.

| 파일 | 확인된 사실 | 공개 상태 |
|---|---|---|
| `models/people_detect.tflite` | TFLite 사람 검출 모델 바이너리, 약 12.1 MB | 비공개 백업 보관 |
| `models/people_label.txt` | 모델 라벨 파일 | 비공개 백업 보관 |
| `warning.wav` | 경고 WAV 약 3.54초 | 비공개 백업 보관 |
| `before.jpg` / `after.jpg` 및 시험 영상 | 캡처·사람 검출 결과와 야외 시험 자료 | 얼굴 등 개인정보로 미공개 |

파일 존재는 검증됐지만, **현재 Raspberry Pi를 보유하지 않아 모델·음원과 코드 전체를 다시 실행해 검증한 것은 아닙니다**. 실제 2023년 최종 배포 버전과의 일치 여부 또한 확정되지 않았습니다.

## Twilio SMS 실제 수신

제출된 휴대전화 메시지 화면에서 다음이 확인됐습니다.

- Twilio trial 계정 문구가 포함된 **위험 알림 SMS를 여러 차례 실제 수신**.
- 표시된 메시지: `명지대학교 골목1, 위험수준 [위험]`, 현재 `src/python/alarm.py`의 본문 구성과 일치.
- 화면에 **최소 10개 메시지**가 보이며, 날짜 구분선 아래 **2023-06-05 17:25** 수신 기록이 포함되어 있습니다.
- 다른 메시지의 시각은 표시되지만, 그 날짜를 화면 하나만으로 단정할 수 없습니다.

**판정:** Twilio 경고 문자의 실제 수신은 확인됐습니다. 하지만 해당 문자가 카메라에서 실제 군중 위험 상황을 자동으로 판정한 결과인지, 수동 DB 입력이나 기타 시험 호출의 결과인지는 이 사진만으로 확인되지 않습니다. 또한 메시지 수신이 **USB 스피커 경고음의 성공**을 입증하지는 않습니다.

위험값이 반복 조회되면 여러 문자가 전송될 수 있는 원본 설계와 부합하지만, 반복 수신의 원인을 스크린샷만으로 확정하지 않습니다.

## 소스 보존 표현에서의 주의점

현재 `main`의 16개 코드/설정 파일은 **이전 공개용 Git 보관본과 동일한 blob SHA를 가진 사본**입니다. 공개 과정에서 평문 DB 비밀번호, Twilio 인증정보와 전화번호를 환경변수로 대체한 이력이 있으므로, **당시 2023년 비공개 원본 ZIP과 바이트 단위로 동일하다는 뜻은 아닙니다.** 명칭은 '당시 코드를 근거로 정리한 보안 처리된 보관 소스'가 정확합니다.

원본 기여 분담은 최종보고서에 기록돼 있으나, Git에 있는 모든 줄을 저장소 소유자가 직접 작성했다는 뜻도 아닙니다.

## 공개 전 보안 점검

- 화면 캡처에 포함된 전화번호, 계정정보, 얼굴은 삭제·가림 처리 전 공개하지 않습니다.
- 2023년 Twilio 인증정보와 Google/Roboflow 등 기존 토큰이 아직 유효하다면 폐기·교체합니다.
- 현재 Git의 과거 커밋·보관 브랜치를 포함한 전체 이력의 완전한 비밀정보 검사는 별도 필요합니다.
- 팀 공동 제작물과 예제 코드의 저작권·라이선스는 `docs/attribution.md`를 참고합니다.
