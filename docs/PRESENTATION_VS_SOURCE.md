# 2023년 최종 발표 ↔ 실제 보관 소스

**근거**: `4조 캡스톤디자인 압사 방지 CCTV 최종.pptx` (세이프워치, 캡스톤디자인 4조), `4조 캡스톤디자인 압사 방지 CCTV 6월1주차.pptx`, 2023 보관 Python·HTML·PHP·SQL. 이 비교표는 **2026년에 작성된 문서**이며 당시 소스코드가 아닙니다.

## 발표와 원본 양쪽에 근거가 있는 핵심 기능

- 카메라 영상 수집: `stream.py`의 Picamera2/MJPEG, `main.py`의 영상 프레임 추출.
- TensorFlow/TFLite 기반 사람 탐지: `count_objects.py`의 이미 변환된 모델 불러오기·추론. 학습·모델 구조 변경은 이 실행 코드에 없음. 모델 변환 후 재학습 또는 수정하지 않았다는 사용자 확인을 우선함.
- 고정된 구역 면적과 인원수: `configs.ini`의 `total_area=300`을 읽어 `people_num / total_area` 연산. **실시간 면적 추정, 보행면적 동적 계산 또는 장애물 면적 차감 기능은 원본에서 실행되지 않음.**
- 이미지: `before.jpg`와 `after.jpg`는 각각 같은 경로로 `cv2.imwrite`하여 새 촬영·추론 결과로 **직접 덮어쓰기**. 웹 `image.php`는 `/tensorflow/after.jpg`를 2초마다 재요청하며 캐시 무효화 시간 쿼리 사용.
- DB 기록 및 Nginx/PHP/AJAX, 밀집도·변화율 그래프, Google 지도, 경고음·Twilio SMS 호출 코드.

## 최종 발표의 인원 기준과 원본 구현의 차이 — 의도적으로 수정하지 않음

| 인원 수 | 최종 발표가 말하는 시연 단계 | `main.py` 보관 원본(면적=300) |
| ---: | --- | --- |
| 1~2명 | 안전 | 안전 |
| 3~4명 | 경고 | 안전 |
| 5명 이상 | 위험 | 5명에서는 안전; 임계값은 `people_num/300`의 2, 4 |

최종 발표 자료는 **안전 1~2명 / 경고 3~4명 / 위험 5명 이상**을 명확히 기재합니다. 그러나 보관 원본 `main.py`의 `get_alert_level`은 `density = people_num / total_area`로 나눈 뒤 `density <= 2`이면 안전, `2 < density < 4`이면 경고, 그 외 위험을 반환합니다.

**결론**: 최종 발표가 기능 기준이고 보관 원본은 실제 확보된 소스입니다. 둘을 임의 수정하여 하나로 위장하지 않습니다. 발표와 정확하게 동작을 맞춘 패치가 나중에 필요하다면, 그 코드는 반드시 원본과 **분리된 수정본**으로 표시해야 합니다.

## 원본의 데이터·경고·모델 세부

- **경고**: 보관 `alarm.py`는 10초마다 최신 DB 위험 수준을 조회하고, 계속 위험이면 매 주기 WAV/Twilio 호출. 300초 cooldown/상태 진입 알림은 2026년 생성 코드였으며 이 `main`에서 제외.
- **DB**: 원본 `schema_legacy_percent.sql`은 직전 밀집도와 비교해 변화율을 산출. 이전 밀집도 0에 대한 나눗셈 방어는 구현된 것으로 확인되지 않음. 2026년 만든 `LAG` 기반 VIEW·`people_count` 컬럼·0 처리 보호는 제외.
- **TFLite 추론**: 원본은 `load_model`에서 Interpreter를 생성하고 추론. 별도의 Interpreter 캐시·최적화는 2026년 재구성 추가였기에 제외.
- **이미지**: 원본은 직접 `cv2.imwrite`로 덮어씀. 임시 JPG → 원자적 rename 방식은 2026년 추가여서 제외.
- **장애물 / IoU**: 중간 발표에는 장애물 분류 학습과 IoU 추가 계획이 있으나, 확인된 최종 `count_objects.py`에서는 장애물 모델 탐지 호출이 주석 처리되어 있음. 이 기능을 완성했다고 단정하지 않으며 새로 구현하지 않음.

**검증 수준**: 소스 함수·SQL·웹 파일과 발표 슬라이드 텍스트 근거의 대조입니다. 2023년 사진·영상에서는 웹·DB·카메라 통합 시연이 확인됐고, 추가 제공된 휴대전화 화면에서 **Twilio 위험 SMS 실제 수신**도 확인됐습니다. 그러나 카메라가 실제 위험을 자동 감지해 발송했는지, 현재 환경에서 전체 시스템이 실행되는지는 미확인입니다. [SMS 및 추가 자산 증거](ARTIFACT_AND_SMS_EVIDENCE.md).
