# Safe Watch — 최종 발표, 2023 개인 최종보고서, 최종 구현 확인의 관계

> **이 문서는 2026년 비교·보정 기록입니다.** 최종 실행 파일 원문을 복원한 증거가 아니라, 2023년 제출자료와 사용자 직접 확인, 기존 공개용 보관 소스의 차이를 설명합니다.

## 위험 단계와 면적 기능

- **당초 설계**: 현장 면적과 장애물 면적을 계산하여 유효 면적 대비 인원을 기준으로 위험을 판단하려고 계획함.
- **개인 최종보고서 7–9쪽의 코드**: `total_area=300` 고정값을 읽고, `get_alert_level(total_area, people_num, obstacle_area)`에서 `density=people_num/(total_area-obstacle_area)`로 계산. 실제 호출은 `obstacle_area=0`. 이 코드의 안전/경고/위험 분기는 밀집도 수치 2,4를 기준으로 함.
- **실제로 완성된 기능에 관한 최종 발표·당사자 확인**: **면적 산출·장애물 차감은 완성하지 못했으며, 위험 수준은 인식된 사람 수로 변경**. 0~2명 안전, 3~4명 경고, 5명 이상 위험. 따라서 보고서의 면적 수치 판정은 **이전 개발 단계**의 구현으로 구분.
- **현행 Git의 `main.py`**: 기존 프로젝트 구조를 살려 `density=people_num/(total_area-0)`를 DB/그래프용 보조 수치로 계산하면서, 위험 단계는 `people_num`에 직접 적용하는 **2026년 최소 수정본**. **사람 수 직접 판정으로 변경했던 2023년 최종 파일의 원문은 현재 미확보**.
- **장애물 인식 모델**: 17가지 종류를 학습했지만 정확도·실행 자원 문제로 최종 Raspberry Pi에 탑재하지 않음. 원본 `get_obstacle_area`는 미완성 함수이므로 자동 면적 측정 기능으로 주장하지 않음.

## 주기·DB·문자·웹의 차이

| 주제 | 2023 개인 최종보고서 | 사용자 확인·현행 Git | 주의 |
| --- | --- | --- | --- |
| 사람 인식/DB 기록 | `configs.ini: delay=10` | 현행 `delay=10` | 루프에서 처리 후 10초 sleep → 실제 시작 간격은 처리 시간 포함 |
| 밀집도 변화 그래프 | 21–22쪽·29쪽: 퍼센트에서 **절대 차이**로 변경했다고 기술하고 `change_rate = current-previous` 사용 | 당사자는 **최종 백분율(%)**이었다고 확인. 현행 `schema_legacy_percent.sql`은 전후값 대비 `/previous*100` | 두 자료 충돌을 보존. 실제 적용됐던 SQL 바이트는 확인하지 못함 |
| 경고 문자 | `alarm.py`의 DB 조회, Twilio | 실제 최종 SMS 발송 주체는 `alarm.py` | `maininfo.html`에 남은 `/send_sms` 호출은 이전 웹 시도 경로 |
| 경고음 | USB 스피커 `aplay`; 웹 Audio 코드도 있음 | Python 경고 경로 보존 | 실제 군중 위험에서 종단 간 검증 기록 없음 |
| 이미지 | 같은 JPG 경로에 직접 덮어쓰기 | `before.jpg` / `after.jpg` 유지, 2초 새로고침 | 임시파일·원자적 파일 교체 미구현 |
| 웹 | Nginx/PHP/MariaDB/AJAX, 밀집도 그래프, 위치 지도 | 보관 소스 기능 유지 | 카메라 스트리밍은 Picamera2 MJPEG 포트 8000 |

## 사용자 설명과 제출 보고서의 정확한 경계

사용자께서는 처음에는 면적을 기반으로 판정하려 했으나 **면적값 산출을 구현하지 못하여 인원 수 방식으로 변경**했다고 명확히 정정했습니다. 이 설명은 2023 최종 발표의 인원 기준과 서로 일치하며, 제출 보고서의 계산식과 충돌하는 이유를 설명합니다.

또한 `configs.ini`의 10초 대 15초 불일치는 보고서의 `10`을 채택해 처리했습니다. **SQL의 절대 차이 대 백분율** 불일치는 사용자가 별도로 최종 사용을 백분율이라고 확인했으므로 기존 백분율 SQL을 유지했습니다.

## 시험 수준

개인 최종보고서 31–33쪽에는 명지대학교·기흥역 인근 야외 시험에서 경고/위험 단계까지 도달하지 못했고, 10m 이상에서 인식률이 낮았으며, 옷 입은 마네킹이 사람으로 인식되는 사례가 기록돼 있습니다. Twilio 경고 문자의 **별도 수신 증거**가 있지만 자동 위험 감지 전체 경로의 실환경 성공을 입증하지는 않습니다.
